Assets & licences

Credits for third-party libraries, sourced audio and assets generated for the GOOSEAGEDDON project.

Attribution status: This page reflects the team's supplied sound register and code review. Confirm individual licences against the original asset pages before redistribution. The licence documentation required by each library should accompany the game release.

AI-generated assets

The team reports generating the map, menus, student and goose artwork, item graphics, seed effects and several audio effects using ChatGPT. These are identified as AI-generated rather than described as CC0 stock assets.

Framework and dependencies

The game uses libGDX (Apache License 2.0) and its LWJGL3 desktop backend (BSD 3-Clause). Include the relevant licence notices in the distributed game package and repository.

Background music

Walk Around by Roa — used without modifying the downloaded recording. Artist: roa-music.com; promoted via Chosic. Recorded licence: CC BY 3.0. Retain track-specific licence evidence for reuse in a downloadable game.
